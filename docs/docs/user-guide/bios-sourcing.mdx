# BIOS File Sourcing

Console emulators require BIOS files extracted from the original hardware. Peach 1UP does
not supply BIOS files. You must dump them from hardware you own. Downloading BIOS files from
the internet is a copyright violation regardless of whether you own the console.

## PlayStation 1

Emulator: DuckStation · Place files in `library/system/bios/ps1/`

### Required files

- **scph1001.bin** — NTSC-U BIOS v2.2. Most commonly used for North American titles.
- **scph5500.bin / scph5501.bin / scph5502.bin** — v3.0 BIOS revisions (JP/US/EU). Required for some later releases.

### How to dump from your own hardware

1. Connect your PS1 to a computer using a modchipped unit or a dedicated BIOS dumping tool.
2. Use a PS1 BIOS dumper (e.g. the open-source caetla or a compatible flash cart) to read the BIOS ROM chip.
3. Save the output as a `.bin` file matching one of the expected filenames listed above.
4. Place the file in `library/system/bios/ps1/` inside your Peach 1UP folder.
5. The Emulators page BIOS section will update automatically once the file is present.

[Official DuckStation BIOS documentation →](https://www.duckstation.org/wiki/BIOS)

## PlayStation 2

Emulator: PCSX2 · Place files in `library/system/bios/ps2/`

### Required files

- **SCPH-70012.BIN (or equivalent)** — NTSC-U PS2 BIOS. The exact filename depends on your console model.

### How to dump from your own hardware

1. Follow the official PCSX2 BIOS dumping guide — it covers extracting the BIOS from your own PS2 using a PS2 memory card exploit or a FreeMCBoot setup.
2. The extracted BIOS folder will contain multiple .BIN and .NVM files — copy the entire set to `library/system/bios/ps2/`.
3. PCSX2 will detect the BIOS automatically on the next launch.

[Official PCSX2 BIOS documentation →](https://pcsx2.net/guides/basic-setup/)

## Xbox (Original)

Emulator: xemu · Place files in `library/system/bios/xbox/`

### Required files

- **MCPX_1.0.bin** — MCPX boot ROM — required. Extracted from the MCPX chip on your Xbox motherboard.
- **Complex_4627v1.03.bin (or equivalent)** — Xbox BIOS ROM — required. Several versions exist; see xemu documentation.

### How to dump from your own hardware

1. Read the xemu documentation for the exact files required and their expected checksums.
2. The MCPX ROM is extracted from the MCPX chip on your Xbox motherboard using specialist hardware (e.g. a TSOP flash programmer).
3. The BIOS ROM can be extracted from an original Xbox with a modchip installed using xenium or a compatible tool.
4. Place the extracted files in `library/system/bios/xbox/`.

[Official xemu BIOS documentation →](https://xemu.app/docs/required-files/)
