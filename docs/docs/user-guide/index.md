# User Guide

Reference material for running and preparing media in Peach 1UP.

- [Era Detection](./era-guide.mdx), what each era means, which file formats belong to it, and how automatic era detection works.
- [Media Formats](./media-formats-guide.mdx), how disc images work, format compatibility by emulator, and how to convert between formats.
- [86Box Hardware Profiles](./86box-hardware-guide.mdx), which hardware profile to choose for Win95/98 games, 3dfx, OPL music, MIDI, or the standard setup.
- [Controller Setup](./controller-guide.mdx), Xbox controller compatibility by emulator, button layout quirks for NES/SNES, and N64 C-button mapping.
- [BIOS File Sourcing](./bios-sourcing.mdx), where to obtain PS1, PS2, and Xbox OG BIOS files from your own hardware.
- [Cartridge Imaging](./cartridge-imaging.mdx), how to dump NES and N64 cartridges from physical hardware using recommended USB dumpers.
