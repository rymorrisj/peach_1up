# Self-Hosting

Notes for running Peach 1UP on your own infrastructure, domains, reverse proxies, and
the environment variables that control them.

## Environment Variables

### DOCS_BASE_URL

Controls the full URL where this docs site is reachable, used both for the backend's
Host-based routing of the bundled docs sub-app and for the "Guides" link in the app
sidebar. Defaults to `http://localhost:3000` for local development. If you're
self-hosting behind your own domain or reverse proxy, set it to that URL instead, e.g.
`https://docs.mydomain.com`. Set in the root `.env` file (see `.env.template`); the
frontend reads the same value via `VITE_DOCS_BASE_URL` in
`frontend/.env.development` / `frontend/.env.production`.
